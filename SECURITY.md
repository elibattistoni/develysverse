# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:
use [GitHub's private vulnerability reporting](https://github.com/elibattistoni/develysverse/security/advisories/new)
for this repository.

Include what you found, where (URL or file), and how to reproduce it.

## Scope

develysverse.com is a static site on GitHub Pages: it has no server code, no accounts,
no forms and no cookies. Reports about the repository, its GitHub Actions workflows,
its dependencies or the hosting setup are welcome.

## Response

This is a personal project, maintained on a best-effort basis. I'll acknowledge a
report as soon as I can and keep you updated while it's being fixed.
